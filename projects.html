CleanFolder – Organizador de Arquivos Pessoais | Projeto Universitário em Equipe

📌 Sobre

CleanFolder é um software em Python que organiza automaticamente os arquivos de uma pasta do usuário, movendo-os para subpastas categorizadas por tipo (imagens, documentos, PDFs, vídeos etc.). Também remove arquivos duplicados e envia arquivos temporários para a lixeira. Ao final, gera um relatório em formato .csv com o resumo da organização Projeto universitário realizado em equipe pelo professor Filipy Galiza Soares na disciplina de Ferramentas de Desenvolvimento e Versionamento.

Você pode conferir o projeto de Vanessa Marques e equipe aqui.


✅ Funcionalidades


1. Detecta o tipo MIME de cada arquivo compython-magic.
2. Cria subpastas automaticamente (ex: /imagens, /documentos, /pdfs, /videos).
3. Mover os arquivos para as pastas corretas.
4. Remova duplicatas por nome e tamanho usandosend2trash.
5. Gera um relatório relatorio .csv com o resumo da organização usando pandas.


💻 Tecnologias

Linguagem: Python 3.11+
Gerenciador de Dependências: pipenv
Bibliotecas de Terceiros: python-magic
send2trash
pandas
